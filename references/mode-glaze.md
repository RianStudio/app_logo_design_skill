# 釉光 Glaze：Apple 原生质感 + 柔和渐变 + 轻微立体

参考气质：Apple 自带 app（天气、提醒事项、备忘录、Freeform）和 iOS 26 的分层图标。像一块上了釉的陶瓷，光很软，很克制。

## 关键词

柔、干净、可信、轻立体、系统感

## 背景

- **同一色相内**从上到下变深：顶部明度高 10–18%。例如天空蓝 `#7DBBFF → #2F7FF0`、草绿 `#7EDB8F → #2FAE52`、暖橙 `#FFB36B → #FF7A1A`、石墨 `#8E9199 → #4A4D55`。
- 再叠一层顶部中心的白色径向光（`cx=512 cy=0 r=760`，白色 28% → 0），让背景像有弧度的釉面。
- 背景色就是品牌色。一枚 Glaze 图标只有这一个色相。

## 主图形

- 默认白色实心，带一点向下的冷色渐变（`#FFFFFF → #D3E5FF`，用背景色相的浅色）。
- 柔和投影：模糊 22、向下 18，投影颜色用**背景色相的深色**（不要灰黑），透明度 0.25–0.3。这就是「轻微立体」。
- 顶部可以有一枚扁椭圆高光（透明度 0.8–0.9），只在主图形上出现一次。
- 次级元素用半透明白（透明度 0.3–0.4），形成前后层次。这也是导入 Icon Composer 做玻璃层的天然分层。
- 形状用圆润的几何：圆、胶囊、大圆角矩形。转角半径大方一点。

## 层次

最多三层，从后往前：背景 → 半透明次级层 → 白色主图形。三层之间的明度差要清楚，小尺寸下靠明度差而不是细节来辨认。

## 不要

- 跨色相渐变
- 拟物纹理（皮革、木纹、纸张）
- 主图形用彩色（白色或者极浅的同色相）
- 硬边投影、长投影
- 超过一处高光
