# 参考与致谢

这个 skill 的结构和部分规则借鉴了以下开源项目，风格规则是 Rian 自己的。

| 项目 | 借鉴了什么 | 许可 |
|---|---|---|
| [Apple Human Interface Guidelines · App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons) | 1024 全出血母版、系统遮罩、分层图标与 Icon Composer、柔和渐变与轻微立体、简洁可辨识的原则 | 设计规范（仅参考） |
| [Notion](https://www.notion.so/) 的图标与插画 | 粗细统一的墨线、圆头、大量留白、一块颜色点出重点的克制用色 | 设计参考（仅参考） |
| [Material Design 3](https://m3.material.io/) 与 Google 产品图标规范 | 产品图标的几何构造与关键线、圆角、自适应图标安全区 | 设计规范（仅参考） |
| [anthropics/skills · canvas-design](https://github.com/anthropics/skills/tree/main/skills/canvas-design) | 「先定义设计哲学再动手」的两段式流程；打磨阶段「只精修、不加东西」的原则；对工艺感的反复强调 | Apache-2.0 |
| [anthropics/skills · frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | 列出 AI 生成设计的常见特征并主动避开；先写方案、对照需求自审、再执行 | Apache-2.0 |
| [op7418/logo-generator-skill](https://github.com/op7418/logo-generator-skill) | 信息收集 → 多方案 → 迭代 → 展示的流程；极简、留白、单一焦点、比例精确等「高级感」原则；SVG 转 PNG 的渲染脚本思路 | MIT |
| [PianoNic/ClaudeSkills · app-icon-expert](https://github.com/PianoNic/ClaudeSkills) | 动笔前的需求检查；纯黑剪影测试；「AI 创业公司图标」反模式；平台规格和交付前的验收清单 | MIT |

本仓库没有复制上述项目的文件，只吸收了方法。
