# 曜石 Obsidian：深色几何 + 精致光泽

参考气质：Linear、Raycast、Arc 的深色图标、Apple Pro 系列产品图。像一件在暗室里被一盏灯照亮的精密零件。

## 关键词

暗、准、冷静、金属、机加工、一点点光

## 背景

- 底色接近黑，但**带一点色温**，不要纯 #000。常用：`#0B0C0F`（中性）、`#0D0F14`（偏冷）、`#120F0E`（偏暖）。
- 用径向渐变做「顶光」：圆心在 `(512, 180)`，半径约 980，中心比边缘亮 8–12%（例如 `#2B2D36 → #15161B → #0B0C0F`）。
- 叠一层从顶部 7% 白到 35% 处透明的线性渐变，模拟玻璃面板的上沿反光。
- 不要网格线、不要星空、不要噪点。

## 主图形

- 由粗壮的几何形构成：圆环、切角方块、扇形、平行四边形、两个图形的布尔运算。线宽用 104 或 64。
- 材质是**拉丝金属或陶瓷**：沿光源方向的线性渐变，`#FFFFFF → #D5D9E2 → #7B8292`，从左上到右下。
- 投影：`feGaussianBlur` 26 + `feOffset dy=28`，黑色透明度 0.5–0.6。深色背景上投影是让图形「浮起来」的关键。
- 可选：在受光的边缘加一条 2–4 px 的高光线（白色，向下渐隐），只加在一处。

## 强调色

- 只有一个点亮的位置：一颗终点、一个缺口、一条切面。面积不超过主图形的 1/6。
- 颜色饱和、偏冷或偏暖二选一。参考：靛蓝 `#5B6CFF`、珊瑚红 `#FF6363`、电光绿 `#3DDC97`、琥珀 `#FFB224`。产品已有品牌色就用品牌色。
- 强调色允许有一层柔和的外发光（`feGaussianBlur` 28，透明度 0.6–0.7），这是全图唯一允许的发光。
- 强调色本身用径向渐变做出一点球面感，再加一个小的白色高光点（透明度 0.5）。

## 不要

- 霓虹描边、赛博朋克紫
- 多处发光
- 金属渐变跨色相（金→紫）
- 把主图形做成透明玻璃（那是 Glaze 的语言）
