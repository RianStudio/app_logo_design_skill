# 风格基因（三种模式共用）

这是 Rian 所有图标的底线。模式决定「穿什么」，基因决定「是谁」。

## 七条原则

1. **一个想法，一个图形。** 图标里只有一个主角。辅助元素最多一个（一个点、一条书签、一圈光晕），而且面积不超过主角的 1/4。
2. **几何先于装饰。** 形状由圆、正方形、45°/30° 角和整数比例构成。先画出纯黑剪影，剪影站得住，才允许加光影和颜色。
3. **克制的颜色。** 最多两个色相，加黑白。同一色相内的明度渐变不算新颜色；跨色相渐变（紫→粉、蓝→橙）一律不用。
4. **光是材质，不是特效。** 渐变、高光、阴影只用来回答一个问题：这个东西是什么材料，光从哪里来。全图只有一个光源，默认在**正上方偏左**。
5. **留白占一半。** 主图形占画布宽度 50%–62%，四周空气感要足。宁可小一点，也不要撑满。
6. **小尺寸下仍然是它。** 60 px 时剪影可辨，29 px 时至少能认出是哪一枚。细节在小尺寸消失没关系，但不能糊成一团。
7. **看起来像花了很多时间。** 曲线衔接连续，线宽统一，间距相等，光的方向一致。每个数字都应该能解释。

## 统一参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血 |
| 主图形关键线框 | 中心 600 × 600（细长形可到 680） |
| 安全区 | 中心 824 × 824（Android 自适应图标裁切后仍完整） |
| 线宽阶梯 | 104 / 64 / 38 / 26（粗 / 中 / 细 / 点缀），一枚图标最多用两档 |
| 圆角 | 图形内部的转角半径用 线宽 × 0.5 或 × 1 |
| 光源 | 左上方 60°，阴影向下偏移 18–28 px |

## 不要做的事

这些是 2024–2026 年 AI 生成图标最常见的特征，看到就改：

- 圆角方块 + 紫蓝或粉橙渐变 + 白色 ✦ 闪光
- 直接打一个字母放在中间
- 品类图标：AI 用大脑/闪光，笔记用铅笔，聊天用气泡，安全用盾牌
- 3 个以上元素平分注意力
- 图标里出现文字或数字
- 写实插画、emoji 风格的表情、复杂的拟物纹理
- 霓虹描边、外发光包裹整个图形、玻璃拟态卡片叠卡片
- 只为「好看」而加的光斑和噪点

## 验收清单（交付前逐条打勾）

- [ ] 纯黑剪影能认出来（对照图里的 mono 版本）
- [ ] 浅色和深色壁纸上都清楚，深色模式下没有「消失」
- [ ] 60 px 能认出形状，16 pt 不糊成一团
- [ ] 只有一个主角，辅助元素 ≤ 1
- [ ] 色相 ≤ 2，没有跨色相渐变
- [ ] 所有光影的方向一致
- [ ] 主图形在 600 关键线框内，全部内容在 824 安全区内
- [ ] 隐喻来自产品的动作，而不是品类
- [ ] 遮住名字，它不会被误认成另一个知名 app
