# 风格规则：简洁、明确、有质感

参考对象：Apple 自带 app 图标（天气、相机、提醒事项、iOS 26 的分层玻璃图标），Google 的产品图标和 Material 3（几何构造、关键线、色块、分层阴影）。

## 原则

1. **简洁：两层就够。** 一个实色图形加一块玻璃。不加第三个元素：没有点缀小星星、没有装饰线。
2. **明确：一眼看懂。** 宁可具象也不要晦涩。用户在主屏上扫一眼就该知道这是什么 app。
3. **几何：每个形都能说出尺寸。** 只用圆、圆角矩形、胶囊、扇形和它们的合并。转角大方（圆角矩形 rx ≥ 宽度的 18%），尖角用 round-join 描边磨圆。
4. **一个光源。** 光从正上方偏左来：背景顶部最亮，实色的高光在左上、暗部在右下，阴影向下落，玻璃上沿最亮。

## 质感：高级感从哪里来

「平」和「高级」的差别，几乎全在下面五件事上。模板已经把它们做好了，画新图标时**一件都不能省**：

| 层 | 做法 | 为什么 |
|---|---|---|
| 背景 | 三档色调的径向渐变（顶部亮、四角深），叠 5%–7% 的细颗粒 | 渐变给空间，颗粒让表面像材料而不是色块 |
| 实色 | 带高光点的渐变（球体用径向、平面用斜向线性），再加右下方的内阴影 | 有亮面、灰面、暗面，物体才有体积 |
| 投影 | 三层：远（模糊 40、下移 36）、中（12、12）、贴地（2、2），颜色用背景最深的色调 | 单层阴影像贴纸，三层才像悬浮的实物 |
| 玻璃 | 模糊 30 并提饱和 1.25，白色 veil 上浓下淡，上沿下方一道内阴影表现厚度 | 透出的颜色要鲜亮，玻璃要有厚度，否则发灰发闷 |
| 边缘光 | 玻璃上沿 7 px 亮边、下沿 4 px 弱亮边（折射） | 上下两道光让玻璃边缘清晰，也是 Apple 玻璃最典型的特征 |

只有会发光的物体（太阳、灯、火焰）才可以加一圈柔光，透明度不超过 0.32。

## 参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角 |
| 主体关键线框 | 中心 600 × 600 |
| 安全区 | 中心 824 × 824 |
| 背景 | 径向渐变，圆心 (512, 40)，半径 1100，三档：亮 / 中（45%）/ 深 |
| 颗粒 | 深色背景白颗粒 7%，浅色背景黑颗粒 5% |
| 实色内阴影 | 偏移 (-14, -18)、模糊 18，实色色相最深的一档，透明度 0.5 |
| 投影 | 远 0.42、中 0.28、贴地 0.22 |
| 玻璃 veil | 0.74 → 0.48；玻璃大部分压在背景上时 0.86 → 0.60；浅色背景上 0.62 → 0.42 |
| 重叠面积 | 实色与玻璃重叠约 25%–45% |

## 推荐配色

颜色要有深度：背景用「亮 / 中 / 深」三档，深档接近黑但带色相。避免 iOS 7 时代那种整片高饱和亮色。

| 背景（亮 / 中 / 深） | 实色（高光 → 主色 → 暗部） | 适合 |
|---|---|---|
| 暮蓝 `#4A7BE0 / #1E3F96 / #0A1640` | 日光黄 `#FFF7D6 → #FFD453 → #F0700F` | 天气、出行、日历 |
| 靛紫 `#6E74F0 / #2E31A6 / #0F1046` | 珊瑚 `#FFC2A0 → #FF8A5C → #E5482E` | 专注、效率、开发者工具 |
| 瓷白 `#FFFFFF / #EEF0F4 / #D9DCE3` | 琥珀 `#FFD978 → #FFB42E → #E88600` | 笔记、文档、写作 |
| 瓷白 `#FFFFFF / #EEF0F4 / #D9DCE3` | 翠绿 `#B8F5C4 → #3FD06A → #12963E` | 健康、财务、完成类 |
| 石墨 `#4A4E58 / #24272E / #0C0D10` | 任一暖色 | 专业工具、相机、夜间使用 |
| 深青 `#3FB8A6 / #146B66 / #06292B` | 日光黄或珊瑚 | 生活、社交、地图 |

白底时，玻璃必须压在实色图形上（白玻璃放在白底上会消失），并靠投影和上沿亮边撑出轮廓。

## 不要

- 字母、文字、数字
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 跨色相的渐变（紫→粉、蓝→橙）
- 超过两层，或者超过两个色相
- 霓虹、整圈外发光（发光体除外）、长投影、硬边投影
- 整片高饱和亮色背景（iOS 7 式扁平）
- 拟物纹理（木纹、皮革、纸纹）；颗粒只能是均匀的细噪点
- 玻璃叠玻璃

## 验收清单

- [ ] 遮住名字，能一眼说出这是什么 app
- [ ] 只有一个实色图形和一块玻璃
- [ ] 色相 ≤ 2，玻璃没有自己的颜色
- [ ] 重叠处是视觉焦点，能看到透过玻璃的模糊颜色
- [ ] 玻璃不发灰，上下两道边缘光都在
- [ ] 实色有亮面和暗面，不是一块平涂
- [ ] 背景有三档色调和细颗粒，不是一片纯色
- [ ] 三层阴影都带背景色相，方向一致向下
- [ ] mono 版本的剪影仍然清楚
- [ ] 60 px 能认出，16 pt 不糊
- [ ] 浅色和深色壁纸上都站得住
- [ ] 主体在 600 关键线框内，视觉重心在中心
