# 风格规则：极简线条

一句话：**一笔墨线画出物件，一块颜色点出重点。** 线条和留白学 Notion 的插画与图标，几何和关键线学 Google 产品图标，柔和的渐变和轻微的立体感学 Apple。

## 原则

1. **一条线、一块色。** 每枚图标只有两样东西：一组粗细统一的墨色线条，加一个强调色色块。不加第三样。
2. **明确：一眼看懂。** 画的是具体的物件（秒表、纸页、相框、云），简化到能用线条一笔画出来。主屏上扫一眼就知道这是什么 app。
3. **线条统一。** 所有线一样粗（1024 画布上 52 px），圆头、圆角拐弯，不用描边粗细变化表达层次。
4. **颜色只点一处。** 强调色填在物件里最有意义的那一块：计时的进度、天气的太阳、扫码的扫描线。色块最好是物件本身的一部分；只有当「结果」本身就是重点时（比如打卡的勾），才用一个圆形印章托住它。色块面积约占主体的 15%–35%。
5. **圆角。** 所有矩形转角 rx ≥ 短边的 18%；线条端点和拐角全部 round。没有尖角。
6. **几何。** 只用圆、圆角矩形、胶囊、圆弧、直线和它们的组合，每个形都能说出尺寸，落在 Google 关键线上。
7. **轻立体。** 背景是很淡的上亮下暗渐变，色块是上浅下深的同色渐变，整个主体下面有一层极淡的投影。像放在桌上的一张纸，而不是 3D 物体。

## 构成

| 层 | 做法 |
|---|---|
| 背景 | 浅色版（默认）：`#FFFFFF → #EEEEEB` 从上到下；深色版：`#3A3A3D → #1C1C1E` |
| 强调色块 | 一个闭合形状，填强调色的「浅 → 主」上下渐变，放在线条**下面**；边缘被线条压住或者完全在线条围出的区域里 |
| 墨线 | `stroke-width="52"`，`stroke-linecap="round"`，`stroke-linejoin="round"`，`fill="none"`；浅色版 `#1C1C1E`，深色版 `#F5F5F7`。线需要挡住色块时，填背景色（浅 `#FFFFFF`、深 `#2A2A2C`） |
| 投影 | 整个主体一层：模糊 22、下移 16，浅色版透明度 0.10，深色版 0.35 |

## 参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角 |
| 主体尺寸 | 外轮廓（含线宽）长边 640–700 px，最大 740。以 Tide 为准：并排放在一起时，每枚的视觉大小要和 Tide 的秒表差不多。实心感强的形状（方形、整页纸）取下限，镂空的形状（取景框、云）可以取上限 |
| 光学居中 | 主体的视觉重心落在画布中心。顶部有凸起（秒表按钮、日历装订环、提手）时，凸起不算，让**主体本身**（表盘、日历页）的中心落在 (512, 530) 附近 |
| 安全区 | 中心 824 × 824 |
| 线宽 | 52 px（约为画布的 5%），所有图标都一样 |
| 线与线的间距 | 两条线描边外沿之间的**净空**至少 78 px（1.5 倍线宽），否则小尺寸会糊在一起；色块和线之间的净空至少 40 px |
| 圆角 | 矩形 rx ≥ 短边 18%；色块的尖角用 `scripts/shapes.py` 算圆角 |

## 颜色

**强调色**（浅 → 主），每枚图标只选一个：

| 名 | 色值 | 适合 |
|---|---|---|
| 蓝 | `#7AAEFF → #3B7BEA` | 默认：工具、效率、扫码、文件 |
| 绿 | `#6FD3A6 → #23A36B` | 健康、财务、完成、环保 |
| 黄 | `#FFD978 → #F2AE2E` | 天气、灵感、笔记、提醒 |
| 珊瑚 | `#FF9C86 → #EC5B45` | 计时、专注、录制、热度 |
| 紫 | `#B3A6FF → #7A63F0` | 创作、音乐、夜间、AI |
| 灰 | `#C8C7C3 → #8E8D89` | 极简、系统工具 |

**墨线**：浅色版 `#1C1C1E`，深色版 `#F5F5F7`。**背景**见「构成」。

默认用浅色版 + 蓝。产品有品牌色时，从上表里选最接近的一个，不要自造颜色。

## 不要

- 字母、文字、数字
- 第二个强调色、彩色线条、线条上的渐变
- 粗细不一的线、细线条装饰、虚线
- 色块加描边、色块加内阴影、玻璃或金属质感、3D 透视
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 线条围出的细碎小格子（小尺寸会糊）
- 背景用强调色铺满（背景永远是浅色或深色中性色）

## 验收清单

- [ ] 遮住名字，能一眼说出这是什么 app
- [ ] 只有一组墨线和一个强调色块
- [ ] 所有线一样粗，端点和拐角都是圆的
- [ ] 色块在线条下面，点在最有意义的那一处，面积 15%–35%
- [ ] 主体长边约 680 px，在系统遮罩的圆角里不被裁到，也不显得空
- [ ] 线与线之间至少 78 px，80 px 尺寸下不糊
- [ ] 对照图里的 mono（去色）版本仍然清楚；只留墨线的着色版另做一份检查
- [ ] 和同类 app 最常见的图标比，至少有一处是这个 app 自己的（物件的细节或色块的位置）
- [ ] 浅色和深色壁纸上都站得住
