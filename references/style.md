# 风格规则：清冷的东方质感

一句话：**青瓷的釉，精密器物的冷静。** 构造和尺寸学 Google 产品图标与 Apple 图标网格（几何、关键线、饱满的主体），光影学 Apple（体积、多层投影），材质和颜色来自中国美学：青瓷釉、传统色；整体气质极简、偏科技、偏冷淡。

## 原则

1. **简洁：两层就够。** 一个实色图形加一层瓷釉。不加第三个元素，没有装饰线，没有纹样。
2. **明确：一眼看懂。** 宁可具象也不要晦涩。用户在主屏上扫一眼就该知道这是什么 app。
3. **饱满：按 Apple 和 Google 的图标网格定尺寸。** 主体要撑得起画面，像系统自带 app 一样一眼就看到；四周保留的只是网格要求的边距，不刻意大面积留白。
4. **清冷：像青瓷，也像精密器物。** 底色偏冷偏灰，实色降饱和；釉清透，背后的颜色只是淡淡透出来；高光克制，边缘一道细而亮的切边。
5. **克制：冷色为主，暖色只做点缀。** 一枚图标里暖色（朱砂、藤黄）的面积不超过主体的一半；能用银白、黛、石青表达的就不用暖色。
6. **几何：每个形都能说出尺寸。** 只用圆、圆角矩形、胶囊、扇形和它们的合并。转角大方（圆角矩形 rx ≥ 宽度的 18%），尖角用 round-join 描边磨圆。
7. **一个光源。** 光从正上方偏左来：底色顶部最亮，实色的高光在左上、暗部在右下，阴影向下落，釉光在上方。

## 质感从哪里来

模板已经做好下面六件事，画新图标时**一件都不能省**：

| 层 | 做法 | 为什么 |
|---|---|---|
| 底色 | 一种冷调传统色分亮 / 中 / 深三档，顶光径向渐变；叠 3% 的细颗粒 | 渐变给空间，极细的颗粒像素胎或磨砂金属，让表面成为材料又不显粗糙 |
| 实色 | 「高光 → 主色 → 暗部」三段渐变，加右下方内阴影。球、日轮这类本来就是球体的用径向渐变；扇形、纸页、图表这类平面图形用左上到右下的线性渐变，否则会鼓成一颗球 | 有亮面和暗面，物体才有体积 |
| 投影 | 三层：远（模糊 28、下移 24）、中（12、12）、贴地（2、2），颜色见色板「投影」列 | 单层阴影像贴纸，三层才像放在桌上的器物；远影收紧，显得利落 |
| 釉身 | 背后画面模糊 26、提饱和 1.25，盖一层釉色。透明度看**釉下面主要是什么**：主要压在深色底上 0.90 → 0.82；主要压在浅亮的实色（藤黄、银白）上 0.80 → 0.70；浅色底上 0.72 → 0.60 | 釉比玻璃厚，颜色只淡淡透出；轻微提饱和防止透出的颜色变脏，但不艳；压在深色上太薄会发灰，压在亮色上太厚又像一块不透明的奶白卡片 |
| 积釉 | 釉面下沿内侧一道很淡的深色带（透明度 0.16），颜色用釉色的深档 | 真实瓷器的釉在下沿积得更厚，这是瓷感的来源；保持很淡，釉面才显得清透 |
| 釉光 | 一片模糊 22 的白色扁椭圆，透明度 0.3，宽约为釉形状宽度的 60%，高约为自身宽度的 30%，贴在釉形状上沿内侧、略偏左；边缘一道 2.5 px 的纯白切边，从上往下渐隐 | 光很克制；细而亮的切边像精密加工的倒角，是科技感的来源 |

只有会发光的物体（太阳、灯、火焰）才可以加一圈柔光，透明度不超过 0.28。

## 参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角 |
| 主体尺寸 | 长边约 720 px（画布的 70%），最大不超过 780 px；参考 Material 产品图标关键线（方形约 79%、圆形约 92% 的 live area）和 Apple 图标网格，按形状调整：方形主体约 700，圆形主体直径约 740，宽扁形（胶囊、云）宽可到 760、高不超过 600 |
| 光学居中 | 主体的视觉重心落在画布中心；阴影在下方，主体可以整体上移 8–16 px |
| 安全区 | 中心 824 × 824 |
| 底色 | 径向渐变，圆心 (512, 40)，半径 1100，三档：亮 / 中（45%）/ 深 |
| 颗粒 | 深色底白颗粒 3%，浅色底深色颗粒 3% |
| 实色内阴影 | 偏移 (-14, -18)、模糊 18，透明度 0.28，颜色见色板「内阴影」列（比暗部再深一档） |
| 投影 | 深色底：远 0.28、中 0.26、贴地 0.2；浅色底：0.17、0.16、0.12。颜色见色板「投影」列；浅色底用冷调深灰蓝，太浓会让底色发脏 |
| 重叠 | 以**釉的面积**为分母，约 30%–80% 压在实色上，其余落在底色上。釉要有一段边越出实色，这段边是质感最明显的地方 |

## 传统色板

全部偏冷、降饱和。暖色只有淡藤黄和淡朱砂两种，只给本身就是暖色的东西（太阳、金币、提醒、进度）。

**底色**（亮 / 中 / 深）：

| 名 | 色值 | 投影 | 气质 |
|---|---|---|---|
| 玄青 | `#3C4854 / #1A222B / #070A0E` | `#000000` | 沉静、专业、工具、夜间 |
| 黛蓝 | `#56708A / #2A3D52 / #0E1724` | `#060B14` | 天空、出行、阅读 |
| 霜白 | `#F6F8F8 / #E5EAEB / #C6CFD2` | `#1E2A33` | 书写、图片、轻量工具 |
| 苍绿 | `#5F7A74 / #2C413D / #0E1817` | `#050B0A` | 健康、自然、财务 |

**实色**（高光 → 主色 → 暗部）：

| 名 | 色值 | 内阴影 | 用在 |
|---|---|---|---|
| 银白 | `#F3F6F7 → #B8C3CA → #6F7C86` | `#2E3940` | 默认的工具色：扫码、设置、计算、文件 |
| 黛 | `#7D90A6 → #3E526A → #1F2C3D` | `#121B27` | 浅底上的主色：笔记、文档、日历 |
| 石青 | `#9CC3E0 → #3F7FB5 → #1F4A78` | `#12304F` | 图片、天空、水、网络 |
| 淡藤黄 | `#F4ECD4 → #D9B46A → #A57F3A` | `#8A5510` | 只给本来是黄色的东西：太阳、金币、灯 |
| 淡朱砂 | `#E4836E → #BF4639 → #8A2A23` | `#6E1712` | 点缀：进度、提醒、录制；面积小于主体的一半 |

**釉色**（上 → 下，积釉深档）：

| 名 | 上 | 下 | 积釉 |
|---|---|---|---|
| 天青 | `#DCEDE8` | `#A5C7C0` | `#3E6B66` |
| 月白 | `#F4F8F6` | `#D6E3E1` | `#5E7A86` |
| 粉青 | `#E3EFE8` | `#B3CFC3` | `#4E7A6C` |

釉压在淡朱砂上时优先用月白，偏绿的天青、粉青和红混在一起容易发脏。

经典搭配：玄青 + 淡朱砂 + 天青，黛蓝 + 淡藤黄 + 月白，霜白 + 黛 + 月白，玄青 + 银白 + 天青，霜白 + 石青 + 月白，苍绿 + 淡藤黄 + 天青。

## 不要

- 字母、文字、数字、印章文字
- 龙凤、祥云、回纹、水墨笔触这类「中国元素」符号：东方感来自材质和颜色，不来自图案
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 高饱和的西式亮色（正红、纯蓝、荧光色），以及大面积的暖色
- 超过两层，超过两个色相（釉色不算）
- 锐利的玻璃亮边、霓虹、整圈外发光（发光体除外）
- 拟物纹理（木纹、皮革、开片裂纹）；颗粒只能是均匀的细噪点

## 验收清单

- [ ] 遮住名字，能一眼说出这是什么 app
- [ ] 只有一个实色图形和一层釉
- [ ] 颜色全部来自传统色板，冷色为主，暖色面积小于主体的一半
- [ ] 釉面清透：能看到背后颜色淡淡透出，下沿有很淡的积釉，上沿有一道细亮切边
- [ ] 实色有亮面和暗面，不是一块平涂
- [ ] 底色有三档色调和极细的颗粒
- [ ] 三层阴影用色板「投影」列的颜色，方向一致向下
- [ ] 主体饱满：长边约占画布 70%，在系统遮罩的圆角里不被裁到，也不显得空
- [ ] mono 版本的剪影仍然清楚
- [ ] 80 px 能认出，16 pt 不糊
- [ ] 浅色和深色壁纸上都站得住
