# 风格规则：极简线条

一句话：**一笔墨线画出物件，一块颜色点出重点。** 线条和留白学 Notion 的插画与图标，几何和关键线学 Google 产品图标，柔和的渐变和轻微的立体感学 Apple。

这份文件是所有数字的唯一出处。不用手量：除了圆角（rx、凹角 r）、接头夹角和安全区，下面的指标 `scripts/render.py` 每次都逐条打印，标 PASS / FAIL / INFO，以它为准。

## 原则

1. **一条线、一块色。** 每枚图标只有两样东西：一组粗细统一的墨线，加一个强调色色块。不加第三样。宽度不超过 2 倍线宽的实心小块（比如二维码的定位块）算作墨线。
2. **明确：一眼看懂。** 画具体的物件（秒表、纸页、相框、云），简化到能用 3–7 段线画出来。主屏上扫一眼就知道这是什么 app。
3. **线条统一。** 所有线一样粗，圆头、圆角拐弯，不用粗细变化表达层次。
4. **颜色只点一处。** 强调色填在物件里最有意义的那一块：计时的进度、天气的太阳、扫码的扫描线。色块最好是物件本身的一部分，也可以就是第二个物件（词典的书签）。只有「结果」本身是重点时（打卡的勾），才让色块托住它，勾标 `on-accent` 躺在色块里。托住它的色块最好自己也有含义（Streak 的连续色带），实在没有再用圆形徽章。
5. **圆角。** 矩形和外轮廓上没有尖角。round join 只磨圆拐角的外侧，折线内侧留下的尖角是允许的；色块和外轮廓上的凹角，用 r ≥ 24 的反向圆弧过渡（见 `examples/ledgerly.svg`）。
6. **几何。** 只用圆、圆角矩形、胶囊、圆弧、直线和它们的组合，每个形都能说出尺寸，落在关键线上。
7. **轻立体。** 背景上亮下暗，色块上浅下深，主体下面一层极淡的投影。投影只落在外轮廓外面，像放在桌上的一张纸，而不是 3D 物体。

## 构成

| 层 | 做法 |
|---|---|
| 背景 `#background` | 浅色中性色上下渐变 |
| 衬底 `#backing` | `#subject` 的第一个子元素，和外轮廓同形（画在线的中心线上），填 `url(#bg)`，挡住落进物件内部的投影。没有封闭的空白时省略：只有括号（QR），或封闭区域已被色块和挖空色填满（Halo） |
| 强调色块 `#accent-shape` | 一个闭合形状，填强调色「浅 → 主」的上下渐变，在线条**下面** |
| 墨线 `#line` | 所有线一个组，round 端点和拐角，`fill="none"`。要挡住色块的闭合线形填挖空色 |
| 投影 `lift` | 作用在整个 `#subject` 上 |

颜色见「颜色」；深色版和着色版由 render.py 生成，配方在 `construction.md`「变体」。

## 参数

所有 px 都指缩放后的最终像素（1024 画布上），不是源坐标。净空按像素量，允许 1 px 误差。

| 项目 | 规则 | 怎么量 |
|---|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角；安全区是中心 824 × 824 | |
| 线宽 | 52（约为画布的 5%） | stroke-width × k，允许 ±1 |
| 主体尺寸 | 按形状画到关键线：圆形外径约 600；方形 540（顶部凸起不计）；竖矩形 480 × 600；横矩形 600 × 480；镂空形状可以大 10%。长边硬上限 740。关键线是起稿尺寸；部件部分重叠或伸出（Halo 的太阳、Ledgerly 的切片）时外框可以超出，以「视觉大小」一行的面积比为准，长边仍 ≤ 740 | 外框含线宽；上限含凸起 |
| 视觉大小 | 实心形状（`data-shape` 为 `circle` / `square` / `tall` / `wide`）：填充剪影面积是 Tide 的 0.90–1.10 倍。镂空或组合形状（`data-shape="open"`：取景框、括号、主体加分开的外部零件）：凸包面积是 Tide 凸包的 0.90–1.15 倍，而且并排时不能比 Tide 显轻，主体框要画饱满。色块就是第二个物件、和主体重叠或相接（翻译气泡、书签）时不算组合，按合起来的外形选实心形状（`tall` 等），查剪影 | 剪影 = 墨线 + 色块，内部填满；凸包含线宽；Tide 的值由 render.py 从 `examples/tide.svg` 现场算 |
| 重心 | 填充剪影的质心离 (512, 512) ≤ 12。顶部有凸起（按钮、装订环、提手）时，改为主体本身（表盘、日历页）的中心落在 (512, 530 ± 6) | 剪影像素的平均位置 |
| 线与线 | 互相分开的线之间净空 ≥ 78。物件内部的线也离内沿 ≥ 78，每条占 130（52 + 78）：内宽 W 里一条横线最长 W − 156（含圆头），竖矩形关键线内宽 376、内高 496，只放得下三行 ≤ 220 的横线。内部要放图形时，把图形交给色块或放大外框 | 两条描边外沿之间的最短距离。相连的线（T 形接头）不算，但接头两侧的夹角要 ≥ 60° |
| 切开的部分 | 同一物件被切开的两部分（抽出的饼图切片）净空 ≥ 52，两部分都标 `data-part="split"` | 同上 |
| 色块与线 | 色块边缘落在线的中心线上，或者离线的描边外沿 ≥ 40 | 见下面「色块的边」 |
| 色块上的线 | 躺在色块里的线（`class="on-accent"`）离色块边缘 ≥ 40 | 描边外沿到色块边缘 |
| 色块面积 | 可见色块占主体凸包的 15%–30%。线状色块（扫描光束，`#accent-shape` 标 `data-accent="line"`）为 8%–15% | 分子只算看得见的色块；分母是主体凸包（含线宽） |
| 圆角 | 矩形 rx ≥ 短边的 20% | 按线的中心线量 rx 和短边 |
| 色块渐变 | 固定跨度 480，中点是色块上下范围的中心 | 源坐标里写 480 ÷ k |
| 投影 | 模糊 22，下移 16，透明度 0.10 | 照抄模板的 `lift` |

## 色块的边

色块的每一段边都必须是下面三种之一，否则会露出一条细边：

1. **压在线下**：边缘正好落在线的中心线上。
2. **在线围出的区域里**：整个色块离所有线的描边外沿 ≥ 40（比如一枚圆形徽章）。
3. **自由边**：不压在线下的那段边由直线或整段圆弧组成，两端落在线的中心线上，离其他线 ≥ 40（Tide 扇形的两条半径、Margin 色条的右边、Streak 色带的上下边和圆头、Halo 露在云外的那段圆弧）。自由边从线下伸出时，和线的中心线夹角要 ≥ 60°，否则会留下一道细楔形。

线状色块（`data-accent="line"`）可以从开口处伸出线框，只要离所有线 ≥ 40（QR 的光束）。

色块的尖角：扇形用 `scripts/shapes.py sector` 算圆角；其余的尖角让它落在线的中心线上，被线压住。

## 颜色

**强调色**（浅 → 主），每枚图标只选一个：

| 名 | 色值 | 适合 | 界面主色 |
|---|---|---|---|
| 蓝 | `#7AAEFF → #3B7BEA` | 默认：工具、效率、扫码、文件 | 蓝 |
| 绿 | `#6FD3A6 → #23A36B` | 健康、财务、完成、环保 | 绿 |
| 黄 | `#FFD978 → #F2AE2E` | 天气、灵感、笔记、提醒 | 蓝 |
| 珊瑚 | `#FF9C86 → #EC5B45` | 计时、专注、录制、热度 | 蓝 |
| 紫 | `#B3A6FF → #7A63F0` | 创作、音乐、夜间、AI | 紫 |
| 灰 | `#C8C7C3 → #8E8D89` | 极简、系统工具 | 蓝 |

「界面主色」是 `rian-app-theme` 生成 UI 主题时的主色。暖色和灰只留在图标里，界面换成蓝；希望界面和图标同色时，只能选蓝、绿、紫。

**背景**：`#FFFFFF → #EEEEEB`，从上到下。**墨线**：`#1C1C1E`。**挖空色**（挡住色块的闭合线形）：`#FFFFFF`。

## 不要

- 字母、文字、数字
- 第二个强调色、彩色线条、线条上的渐变
- 粗细不一的线、细线条装饰、虚线
- 色块加描边、色块加内阴影、玻璃或金属质感、3D 透视
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 线条围出的细碎小格子（小尺寸会糊）
- 背景用强调色铺满（背景永远是中性色）
- 照搬同名 SF Symbol 的轮廓，或者沿用 examples 里的整体框架

## 验收清单

render.py 报告里有的数值不再列；这里是要用眼睛判断或手查的：

- [ ] render.py 报告没有 FAIL；修不掉的写进交付的「可再调」
- [ ] 遮住名字，80 px 下能一眼说出这是什么 app，不会读成别的东西（脸、括号、列表）
- [ ] 写出同名 SF Symbol / Material Symbol 的轮廓，在交付说明里写一句差异在哪（至少 1 处轮廓或结构差异）
- [ ] 矩形 rx ≥ 短边 20%，凹角 r ≥ 24，接头两侧夹角 ≥ 60°，主体在中心 824 × 824 以内
- [ ] 只有一组墨线和一个强调色块，端点和拐角都是圆的
- [ ] 和 Tide 并排时一样大、一样重
- [ ] 物件里面没有投影的灰圈
- [ ] 深色版和着色版里，色块的含义还在
- [ ] 浅色和深色壁纸上都站得住
