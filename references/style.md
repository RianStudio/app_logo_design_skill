# 风格规则：东方质感

一句话：**Apple 的精致，宋瓷的温润。** 构造和尺寸学 Google 产品图标与 Apple 图标网格（几何、关键线、饱满的主体），光影学 Apple（体积、多层投影），材质和颜色来自中国美学：青瓷釉、传统色。

## 原则

1. **简洁：两层就够。** 一个实色图形加一层瓷釉。不加第三个元素，没有装饰线，没有纹样。
2. **明确：一眼看懂。** 宁可具象也不要晦涩。用户在主屏上扫一眼就该知道这是什么 app。
3. **饱满：按 Apple 和 Google 的图标网格定尺寸。** 主体要撑得起画面，像系统自带 app 一样一眼就看到；四周保留的只是网格要求的边距，不刻意大面积留白。
4. **温润：像瓷，不像塑料。** 釉面半透、偏厚、柔光，背后的颜色只是微微透出来；高光是一大片柔和的釉光，不是锐利的反光点。
5. **几何：每个形都能说出尺寸。** 只用圆、圆角矩形、胶囊、扇形和它们的合并。转角大方（圆角矩形 rx ≥ 宽度的 18%），尖角用 round-join 描边磨圆。
6. **一个光源。** 光从正上方偏左来：底色顶部最亮，实色的高光在左上、暗部在右下，阴影向下落，釉光在上方。

## 质感从哪里来

模板已经做好下面六件事，画新图标时**一件都不能省**：

| 层 | 做法 | 为什么 |
|---|---|---|
| 底色 | 一种传统色分亮 / 中 / 深三档，顶光径向渐变；叠 6% 的细颗粒 | 渐变给空间，颗粒像宣纸或素胎，让表面成为材料 |
| 实色 | 「高光 → 主色 → 暗部」三段渐变，加右下方内阴影 | 有亮面和暗面，物体才有体积 |
| 投影 | 三层：远（模糊 40、下移 36）、中（12、12）、贴地（2、2），颜色用底色最深的色调 | 单层阴影像贴纸，三层才像放在桌上的器物 |
| 釉身 | 背后画面模糊 34、提饱和 1.5，盖一层釉色（上 0.72–0.8，下 0.66–0.7） | 釉比玻璃厚，颜色只「晕」出来；提饱和防止透出的颜色变脏 |
| 积釉 | 釉面下沿内侧一道柔和的深色带，颜色用釉色的深档 | 真实瓷器的釉在下沿积得更厚、颜色更深，这是瓷感的关键 |
| 釉光 | 釉面左上一片模糊 22 的白色椭圆，透明度 0.42；边缘一道 4 px 细亮线 | 温润的大片柔光，而不是玻璃那种锐利亮边 |

只有会发光的物体（太阳、灯、火焰）才可以加一圈柔光，透明度不超过 0.28。

## 参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角 |
| 主体尺寸 | 长边约 720 px（画布的 70%），最大不超过 780 px；参考 Material 产品图标关键线（方形约 79%、圆形约 92% 的 live area）和 Apple 图标网格，按形状调整：方形主体约 700，圆形主体直径约 740，宽扁形（胶囊、云）宽可到 760、高不超过 600 |
| 光学居中 | 主体的视觉重心落在画布中心；阴影在下方，主体可以整体上移 8–16 px |
| 安全区 | 中心 824 × 824 |
| 底色 | 径向渐变，圆心 (512, 40)，半径 1100，三档：亮 / 中（45%）/ 深 |
| 颗粒 | 深色底白颗粒 6%，浅色底暖褐颗粒 6% |
| 实色内阴影 | 偏移 (-14, -18)、模糊 18，实色最深档，透明度 0.45 |
| 投影 | 远 0.38、中 0.26、贴地 0.2 |
| 重叠面积 | 实色与釉重叠约 25%–45% |

## 不要

- 字母、文字、数字、印章文字
- 龙凤、祥云、回纹、水墨笔触这类「中国元素」符号：东方感来自材质和颜色，不来自图案
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 高饱和的西式亮色（正红、纯蓝、荧光色）
- 超过两层，超过两个色相（釉色不算）
- 锐利的玻璃亮边、霓虹、整圈外发光（发光体除外）
- 拟物纹理（木纹、皮革、开片裂纹）；颗粒只能是均匀的细噪点

## 验收清单

- [ ] 遮住名字，能一眼说出这是什么 app
- [ ] 只有一个实色图形和一层釉
- [ ] 颜色全部来自传统色板，没有西式亮色
- [ ] 釉面温润：能看到背后颜色微微晕出，下沿有积釉，上方有大片柔光
- [ ] 实色有亮面和暗面，不是一块平涂
- [ ] 底色有三档色调和细颗粒
- [ ] 三层阴影都带底色色相，方向一致向下
- [ ] 主体饱满：长边约占画布 70%，在系统遮罩的圆角里不被裁到，也不显得空
- [ ] mono 版本的剪影仍然清楚
- [ ] 60 px 能认出，16 pt 不糊
- [ ] 浅色和深色壁纸上都站得住
