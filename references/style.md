# 风格规则：简洁、明确、有质感

参考对象：Apple 自带 app 图标（天气、相机、提醒事项、iOS 26 的分层玻璃图标），Google 的产品图标和 Material 3（几何构造、关键线、色块、分层阴影）。

## 原则

1. **简洁：两层就够。** 一个实色图形加一块玻璃。不加第三个元素：没有点缀小星星、没有装饰线、没有背景纹理。
2. **明确：一眼看懂。** 宁可具象也不要晦涩。用户在主屏上扫一眼就该知道这是什么 app。抽象只在产品本身抽象时使用。
3. **有质感：光、玻璃、厚度。** 质感来自三件事，缺一不可：背景的柔和渐变和顶光，实色图形的两段式投影，玻璃的模糊和受光边缘。除此之外不加任何效果。
4. **几何：每个形都能说出尺寸。** 只用圆、圆角矩形、胶囊、扇形和它们的合并。转角半径大方（圆角矩形 rx ≥ 宽度的 18%），扇形的角度用有意义的数字。
5. **一个光源。** 光从正上方来：背景顶部更亮，图形顶部更亮，阴影向正下方落，玻璃的高光在上沿。

## 参数

| 项目 | 值 |
|---|---|
| 画布 | 1024 × 1024，全出血，不画圆角 |
| 主体关键线框 | 中心 600 × 600 |
| 安全区 | 中心 824 × 824 |
| 背景渐变 | 同色相，顶部比底部亮 10–18%，加顶部白色径向光 22% |
| 实色图形渐变 | 同色相，顶部亮、底部深，明度差约 12% |
| 投影 | 环境光：模糊 24、下移 20、透明度 0.22–0.32；接触光：模糊 3、下移 4、透明度 0.18–0.22；颜色用背景色相最深的那一档 |
| 玻璃模糊 | 18 |
| 玻璃 veil | 白色或背景色相极浅的一档，透明度 0.4–0.6（主要压在背景上时取高值） |
| 玻璃高光 | 8 px 内描边，白色从上沿 95% 渐隐到 35% 处为 0 |
| 重叠面积 | 实色与玻璃重叠约 25%–45% |

## 推荐配色

背景一个色相，实色一个色相，冷暖对比最稳：

| 背景 | 实色 | 适合 |
|---|---|---|
| 天蓝 `#6DB6FF → #2A74E6` | 暖黄 `#FFE27A → #FFB41F` | 天气、出行、日历 |
| 靛蓝 `#7480FF → #3B43D2` | 珊瑚 `#FF9A6B → #FF5A3C` | 专注、效率、开发者工具 |
| 白 `#FFFFFF → #ECEEF2` | 琥珀 `#FFC94A → #F59E00` | 笔记、文档、写作 |
| 白 `#FFFFFF → #ECEEF2` | 草绿 `#6EE08A → #22B04B` | 健康、财务、完成类 |
| 深石墨 `#3A3D46 → #15171C` | 任一饱和暖色 | 专业工具、相机、夜间使用 |
| 薄荷 `#5EE6C8 → #12B39A` | 珊瑚或暖黄 | 生活、社交、轻量工具 |

白底时，玻璃必须压在实色图形上（白玻璃放在白底上会消失），并靠投影和高光撑出轮廓。

## 不要

- 字母、文字、数字
- ✦ 闪光、大脑、魔杖这类 AI 符号
- 跨色相的渐变（紫→粉、蓝→橙）
- 超过两层，或者超过两个色相
- 霓虹、外发光、长投影、硬边投影
- 拟物纹理（木纹、皮革、纸张颗粒）
- 玻璃叠玻璃

## 验收清单

- [ ] 遮住名字，能一眼说出这是什么 app
- [ ] 只有一个实色图形和一块玻璃
- [ ] 色相 ≤ 2，玻璃没有自己的颜色
- [ ] 重叠处是视觉焦点，能看到透过玻璃的模糊颜色
- [ ] 玻璃不发灰，上沿有高光
- [ ] 阴影是带色的，方向一致向下
- [ ] mono 版本的剪影仍然清楚
- [ ] 60 px 能认出，16 pt 不糊
- [ ] 浅色和深色壁纸上都站得住
- [ ] 主体在 600 关键线框内，视觉重心在中心
